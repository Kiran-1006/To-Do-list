# 📝 To-Do List

A clean and simple **To-Do List / Routine List** built using **HTML, CSS, and JavaScript** to help users organize tasks and stay productive.

## ✨ Features

* ➕ Add new tasks
* 🗑️ Delete tasks
* 📱 Simple and user-friendly interface
* 🎨 Clean and responsive design

## 🛠️ Technologies Used

* **HTML5** – Structure of the webpage
* **CSS3** – Styling and responsive design
* **JavaScript** – Task management and functionality

## 🎯 Purpose

This project was created to practice **HTML, CSS, and JavaScript** and to build a useful real-world web application.
